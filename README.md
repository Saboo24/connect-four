## 🕹️ THE GAME

Welcome to **Connect Four**, a strategic game where every move matters.

Challenge a friend in local multiplayer or test your strategy against an AI opponent. Drop your discs, block your opponent, and connect four pieces before they do!

> 🔥 **Your mission:** Connect four discs horizontally, vertically, or diagonally to claim victory.

## ✨ FEATURES

| Feature | Description |
|:---|:---|
| 🎮 **Two Game Modes** | Play against a friend or challenge the AI. |
| 🤖 **AI Opponent** | Test your strategy against a computer-controlled player. |
| 🎨 **Modern Interface** | A graphical desktop interface powered by Pygame. |
| 🔴 **Red Player** | Control the red discs. |
| 🟡 **Yellow Player** | Control the yellow discs. |
| 🏆 **Win Detection** | Detects horizontal, vertical, and diagonal victories. |
| 🤝 **Draw Detection** | Recognizes when the board is full without a winner. |
| 🔄 **Restart System** | Start a fresh match whenever you want. |

## 🚀 GETTING STARTED

### Requirements

- Python 3
- pip
- Pygame

### 01 — Clone the repository

```bash
git clone https://github.com/Saboo24/connect-four.git
```

### 02 — Enter the project directory

```bash
cd connect-four
```

### 03 — Install Pygame

```bash
python -m pip install pygame
```

### 04 — Launch the game

```bash
python main.py
```

🎉 **You're ready to play!**

---

## 🎯 HOW TO PLAY

**01.** Launch the application.

**02.** Choose your preferred game mode.

**03.** Select a column to drop your disc.

**04.** Plan your moves and block your opponent.

**05.** Connect four discs to win!

### 🏆 The Winning Conditions

- ➡️ Four discs horizontally
- ⬇️ Four discs vertically
- ↘️ Four discs diagonally

**One board. Two players. One winner.**
